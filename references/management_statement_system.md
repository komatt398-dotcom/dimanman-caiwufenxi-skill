# 经营者表述验证系统 v3.1

本文件定义如何使用年报 MD&A、半年报/季报说明、业绩说明会、投资者关系活动记录表和公开路演材料。核心思想：

> 管理是语言活动；财务分析的任务之一，是验证经营者公开说过的话是否被经营结果支持。

## 1. 来源优先级

按问题类型确定来源权重：

| 问题类型 | 主来源 | 补充来源 | 禁止做法 |
|---|---|---|---|
| 财务数字、会计口径、审计事项 | 年报、半年报、季报、审计报告、公告 | 无 | 用路演、媒体或纪要覆盖财报数字 |
| 管理层如何看市场 | 年报/半年报 MD&A、经营情况讨论 | 业绩说明会、投资者关系活动记录表、公司公开路演材料 | 只摘一句口号，不做财务验证 |
| 经营动作和优先级 | 年报/半年报、董事会报告、经营计划 | 业绩说明会、IR 活动记录、公司官网公开材料 | 把管理层计划写成已经发生的事实 |
| 行业判断 | 财报行业段落、监管/协会/统计资料 | 路演解释、公司公开演示材料 | 无外部证据时写“行业出清”“格局改善”等强判断 |
| 未披露经营细节 | 无 | 只能列为数据缺口或待验证假设 | 用推测补全同店、客户、订单、库存库龄等内部数据 |

公开路演、业绩说明会和投资者关系活动记录表可以进入分析，但必须标注为“管理层公开表述”。它们不替代审计财报，不替代法定披露，也不直接证明经营事实。

## 2. 经营者表述矩阵

当公开材料包含管理层对市场、策略、产品、渠道、成本、现金、风险或资本配置的解释时，报告应建立表述矩阵：

| 字段 | 要求 |
|---|---|
| statement_id | 例如 ST01 |
| source_id | 关联 disclosures 中的财报、说明会或路演来源 |
| speaker_or_document | 董事长、总经理、财务负责人、董事会报告、IR 记录等 |
| statement_date | 公开表述日期 |
| topic | 市场、价格、渠道、产品、成本、现金、并购、风险等 |
| original_statement | 原文或不超过一句的忠实摘录 |
| normalized_statement | 转成可验证的经营命题 |
| statement_type | fact_explanation、strategy_intent、market_view、risk_view、target_or_guidance |
| verification_metric_ids | 用哪些财务或经营指标验证 |
| verification_result | supported、partly_supported、not_supported、not_yet_verifiable、contradicted |
| report_usage | core_judgment、supporting_context、data_gap、appendix_only |

如果同一信息同时出现在财报和路演中：

1. 财务口径、数值、会计解释以财报为准。
2. 管理层语气、原因解释、后续动作可以用路演补充。
3. 正文写法应为“财报披露……；管理层在公开交流中进一步解释……；财务数据目前支持/尚未支持……”

## 3. 验证链

每条重要经营者表述至少接受一种验证：

- **同向验证**：管理层说收入质量改善，检查同店、分部收入、毛利率、退货/折扣、现金回款是否同向。
- **反向验证**：管理层说主动优化门店，检查新开/关闭门店、销售费用、租赁负债、商誉、单店收入或回收期是否支持。
- **时间验证**：管理层说短期扰动，检查后续一个或两个报告期是否恢复。
- **边界验证**：管理层说风险可控，检查债务期限、现金覆盖、受限资金、减值敏感性、客户/供应商集中度等边界指标。
- **不可验证处理**：公开资料无法验证时，写成数据缺口，不写成结论。

## 4. 正文表达

报告中可以设置动态小节：

```text
管理层公开表述与财务验证
```

该小节只在有足够公开表述时出现，结构为：

1. 财报中怎么说。
2. 公开路演/说明会补充了什么。
3. 财务数据是否支持。
4. 还缺哪些验证数据。

禁止写成访谈摘录堆砌。每条表述都要回到一个经营问题、一个验证指标或一个数据缺口。

## 5. 语言边界

避免模型式命名和咨询黑话。优先使用财报、审计报告和公开场合自然语言：

| 避免 | 推荐 |
|---|---|
| 收缩式提质 | 关闭低效门店、放缓低回报扩张、提高单店经营质量 |
| 非内生扩张 | 并购扩张、外延扩张；能不用则不用 |
| 增长换挡期 | 收入增速放缓；从门店数量扩张转向存量门店经营 |
| 剪刀差扩大 | 收入、利润和现金流变化方向不一致 |
| 经营现金流下滑，是扰动还是趋势 | 经营现金流下降需区分结算时点影响和营运资本变化 |
| 经营现金流变动桥 | 净利润调节为经营活动现金流净额的分项分析 |
| 行业出清期 | 有外部证据才写；否则写行业竞争加剧、价格压力或删除 |
| 优先行动卡 | 管理建议、后续关注事项、监控清单 |
| 现金转换驾驶舱 | 现金流监控表、营运资本跟踪表 |

如果一个词不能在董事会材料、审计沟通、业绩说明会或财务负责人汇报中自然出现，应改写。

## 6. 审计要求

报告生成前自查：

- 是否检索了定期报告之外的公开管理层表述来源，或说明未找到。
- 是否把路演信息标注为管理层公开表述，而不是事实。
- 是否存在“路演替代财报数字”的情况。
- 是否每条重要管理层表述都有验证指标、验证结果或数据缺口。
- 是否删除了模型式命名和不必要的咨询黑话。
