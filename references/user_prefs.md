# 用户稳定偏好（User Preferences）

> 本文件只在用户明确要求「更新 / 固化 / 沉淀 skill」时修改。普通财报分析任务不得自动捕捉偏好并回写。

## 已明确偏好

- **报告目标**：读者看完要有获得感，能带走 3 个判断、2 条边界、1 个反证指标。
- **目标读者**：优先面向管理层和业务负责人，重点是经营问题、边界、动作和预警；默认不做估值、目标价和市场情绪。
- **完成优先**：不刻意追求披露字段完整。披露不足时可以降级、留数据缺口或省略模块，但不能伪造完整。
- **结构偏好**：采用“固定决策底座 + 动态诊断模块”。固定底座包括判断面板、一页经营概览、2-4 个核心经营问题、行动卡、监控预警表和证据附录。
- **来源与口径**：指标口径严谨性和来源可追溯性是最高优先级。关键指标必须写原始披露名称、公式、口径、期间、单位、来源链和可比性。
- **claim 分级**：事实、计算、支持性推断和待验证假设必须区分。假设不能写成事实，不能放进无保留核心判断。
- **经营者表述验证**：管理是语言活动，财务分析要验证经营者公开说过的话。年报、半年报、季报和公告用于财务数字与口径；业绩说明会、投资者关系活动记录表和公开路演用于补充管理层对市场、策略和经营动作的解释。
- **路演使用边界**：财报中与公开路演重复的信息，以财报解读为主；路演只作为管理层解释补充。路演不能替代财报数字，不能补全未披露的同店、客户、订单、库存库龄等内部数据。
- **同行分析**：只在需要判断“行业共性还是公司问题”时使用，价值在归因，不在排名。
- **情景分析**：只在驱动关系清楚且会改变管理动作时使用。关系弱时输出方向性风险树，不输出精确数字。
- **图表原则**：图表数量不设下限。先有管理问题，再决定是否画图；没有决策价值的图不画。
- **视觉风格**：前面深蓝色压抑，优先米白、暖灰、低饱和公司色。只在大段落之间使用 subtle divider，内部不堆分隔线。
- **图表位置与单位**：图表标题、takeaway、单位放在图正文之上；单位不能被 SVG 裁切；正文和图表宽度保持一致。
- **图形样式**：费用率等多年同量纲指标优先折线；横向条形有标注时去掉横轴；桥图必须首尾衔接；债务图不要在图内放长段文字。
- **正文重点**：重要判断、风险阈值和反证条件可以有限度使用粗体、风险红和下划线。不要整段变红。
- **语言风格**：避免 AI 式概念命名和咨询黑话。优先财务术语与公开场合自然语言，例如“收入增速放缓”“经营现金流下降需区分结算时点影响和营运资本变化”，少用“增长换挡期”“现金转换驾驶舱”“优先行动卡”等包装词。
- **陈列结构**：事实、影响、分析、红线、必盯指标等可枚举内容逐条分行。多项使用 01 / 02 / 03，单项使用短横标记；禁止重复 1.。
- **交付格式**：财报报告默认输出完整 HTML；Markdown 可作为可编辑源文件同步保留。需要 PDF 时再用 Edge 无头打印生成。
- **自动进化**：保持关闭。只有用户明确要求更新或固化 skill 时，才允许修改 skill 文件。
